<summary style="font-size: 2em; font-weight: bold;">McNemar检验</summary>

McNemar检验是一种用于比较两个相关分类模型性能的非参数统计检验方法。

## McNemar检验的特点：

1. **用途**：
   - 比较两个分类模型在相同数据集上的性能差异
   - 判断模型改进是否具有统计显著性
   - 适用于配对样本的二分类结果比较

2. **基本原理**：
   - 基于两个模型在相同测试样本上的预测结果构建列联表
   - 关注的是两个模型预测不一致的情况
   - 检验零假设：两个模型的性能无显著差异

3. **列联表结构**：
   ```
              模型2正确  |  模型2错误
   模型1正确      a      |      b
   模型1错误      c      |      d
   ```


4. **检验统计量**：
   - 只考虑模型预测不一致的情况（b和c）
   - 统计量公式：$\huge \chi^2 = \frac{(|b - c| - 1)^2}{b + c}$
   - 服从自由度为1的卡方分布

5. **应用场景**：
   - A/B测试结果分析
   - 机器学习模型对比
   - 医学诊断方法比较
   - 推荐系统算法评估

在您提供的代码中，McNemar检验被用来比较逻辑回归和随机森林两个模型在相同训练集上的分类性能差异，并判断这种差异是否具有统计显著性。

<summary style="font-size: 2em; font-weight: bold;">逻辑回归(Logistic Regression)</summary>

逻辑回归是一种广泛应用于分类问题的统计学习方法，特别适合二分类任务。

## 基本概念

逻辑回归虽然名字中有"回归"，但实际上是一种分类算法。它通过sigmoid函数将线性回归的输出映射到(0,1)区间，表示属于某一类别的概率。

## 数学原理

### 1. 线性组合
首先计算输入特征的线性组合：
$$z = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + ... + \beta_n x_n = \mathbf{\beta}^T \mathbf{x}$$

其中：
- $\beta_0$ 是截距项（偏置）
- $\beta_1, \beta_2, ..., \beta_n$ 是各特征的系数（权重）
- $x_1, x_2, ..., x_n$ 是输入特征

### 2. Sigmoid函数
通过sigmoid函数将线性组合映射到概率：
$$P(y=1|\mathbf{x}) = \sigma(z) = \frac{1}{1 + e^{-z}}$$

该函数具有以下性质：
- 输出范围：$(0, 1)$
- 当$z \to +\infty$时，$\sigma(z) \to 1$
- 当$z \to -\infty$时，$\sigma(z) \to 0$
- 在$z = 0$处，$\sigma(z) = 0.5$

### 3. 决策边界
通常以0.5作为分类阈值：
$$\hat{y} = \begin{cases} 
1, & \text{if } P(y=1|\mathbf{x}) \geq 0.5 \\
0, & \text{if } P(y=1|\mathbf{x}) < 0.5
\end{cases}$$

这等价于：
$$\hat{y} = \begin{cases} 
1, & \text{if } \mathbf{\beta}^T \mathbf{x} \geq 0 \\
0, & \text{if } \mathbf{\beta}^T \mathbf{x} < 0
\end{cases}$$

## 损失函数

逻辑回归使用对数似然函数作为目标函数，通过最大似然估计来学习参数：

对于单个样本：
$$\mathcal{L}(\beta) = y \log(\hat{y}) + (1-y) \log(1-\hat{y})$$

对于整个数据集，损失函数为：
$$\huge J(\beta) = -\frac{1}{m} \sum_{i=1}^{m} [y^{(i)} \log(\hat{y}^{(i)}) + (1-y^{(i)}) \log(1-\hat{y}^{(i)})]$$

其中$m$是样本数量。

## 参数估计

通常使用梯度下降法来优化参数：

$$\huge \beta_j := \beta_j - \alpha \frac{\partial J(\beta)}{\partial \beta_j}$$

其中$\alpha$是学习率。

## 优点

- 输出具有良好的概率意义
- 不需要假设特征分布
- 计算效率高
- 不需要特征缩放（但建议进行）
- 不容易过拟合
- 可以加入正则化项防止过拟合

## 缺点

- 假设特征与对数几率呈线性关系
- 对异常值敏感
- 需要大量数据才能得到稳定的结果

在提供的代码中，`LogisticRegression`类被用于实现逻辑回归模型，用于分类任务并参与后续的模型性能比较和特征重要性分析。

<summary style="font-size: 2em; font-weight: bold;">随机森林(Random Forest)</summary>

随机森林是一种集成学习方法，通过构建多个决策树并综合它们的预测结果来提高模型性能。

## 基本概念

随机森林属于Bagging类集成算法，通过引入随机性来降低模型方差，避免过拟合。

## 核心原理

### 1. Bootstrap采样
从原始训练集中有放回地随机抽取样本，构建多个不同的训练子集：
- 每个子集大小与原数据集相同
- 平均有约63.2%的样本被选中

### 2. 特征随机选择
在每个节点分裂时，从所有特征中随机选择部分特征进行最佳分割：
- 通常选择 $\sqrt{总特征数}$ 个特征
- 增加模型多样性，减少过拟合风险

### 3. 多棵决策树
构建多棵独立的决策树，每棵树都在一个Bootstrap样本上训练。

### 4. 集成预测
对于分类问题，采用多数投票；对于回归问题，采用平均值：
$$\hat{y} = \frac{1}{T}\sum_{i=1}^{T} \hat{y}_i$$

其中 $T$ 是树的数量，$\hat{y}_i$ 是第 $i$ 棵树的预测。

## 算法步骤

1. 从原始数据集中进行Bootstrap采样，生成多个训练子集
2. 对每个训练子集：
   - 构建决策树
   - 在每个节点分裂时随机选择特征子集
   - 不进行剪枝，生长到最大程度
3. 将所有决策树组合成森林
4. 预测时让所有树投票决定最终结果

## 优势特点

- **高准确性**: 集成多个弱学习器，通常比单一决策树效果好
- **抗过拟合**: 通过随机性和集成机制有效控制过拟合
- **处理缺失值**: 能较好地处理缺失数据
- **特征重要性**: 可以评估特征的重要性
- **无需特征缩放**: 对特征尺度不敏感
- **并行化**: 树之间相互独立，可并行训练

## 关键参数

- `n_estimators`: 树的数量
- `max_features`: 每次分裂考虑的最大特征数
- `max_depth`: 树的最大深度
- `min_samples_split`: 内部节点分裂所需的最小样本数
- `min_samples_leaf`: 叶节点所需的最小样本数

在提供的代码中，`RandomForestClassifier` 类被用于实现随机森林分类器，设置了 `n_estimators=100` 和 `random_state=42` 参数，与其他模型进行性能比较。
