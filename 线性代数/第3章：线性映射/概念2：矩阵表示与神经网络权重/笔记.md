数学概念：每个线性映射都有对应的矩阵表示

问题：神经网络中的每一层（尤其是全连接层）可以看作是一个线性变换（乘以权重矩阵）加上非线性激活函数。，这里面，每一层是什么意思？神经网络有很多层吗？
- **每一层的含义**：  
  在神经网络中，`layer`（层）指的是一个处理单元，通常由以下两部分组成：
  - **线性变换**：输入数据 [x](file://C:\Users\EDY\Desktop\code\Learning-Notes\线性代数\.venv\Lib\site-packages\pip\_vendor\pygments\console.py#L28-L28) 与权重矩阵 `W` 相乘，并加上偏置项 `b`，即 `z = Wx + b`。
  - **非线性激活函数**：对线性输出 `z` 应用激活函数（如 `ReLU`, `Sigmoid` 等），得到最终输出 `a = f(z)`。

  因此，一个典型的层可以表示为：
  ```
    a = f(Wx + b)
  ```

  其中 `f` 是激活函数，`W` 和 `b` 是该层可学习的参数。

- **神经网络有多少层？**  
  ✅ 是的，神经网络通常包含多个层。根据结构不同，可分为：
  - **输入层**：接收原始输入数据。
  - **隐藏层**：位于输入层和输出层之间的中间层，数量可以是 1 层或多层（深度越深，模型越复杂）。
  - **输出层**：产生最终预测结果。

  例如，一个简单的多层感知机（MLP）可能有：
  ```
  输入层 → 隐藏层1 → 隐藏层2 → 输出层
  ```


  深度学习中的“深度”就是指隐藏层的数量较多（如几十甚至上百层）。

- **总结**：  
  - 每一层执行一次线性变换 + 非线性激活。  
  - 神经网络确实包含多个层，层数越多，模型表达能力越强，但也可能导致训练难度增加。
